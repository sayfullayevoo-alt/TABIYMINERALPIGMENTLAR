# Tabiiy mineral pigmentlar

Ushbu loyiha tabiiy mineral pigmentlar mahsuloti uchun mobil qurilmalarga mos, uch tilli (o‘zbek, rus va ingliz) tanishtiruv veb-saytidir.

## Fayllar
- `index.html` — sayt sahifasi va til almashtirgichi.
- `tabiiy-mineral-pigmentlar.png` — foydalanuvchi taqdim etgan mahsulot posteri.
- `buxdu-logo.png` — Buxoro davlat universitetining asl logotipi; sayt sarlavhasida ishlatiladi.

## Mahsulot haqida
Azkamar (Shofirkon) gil tuprog‘i — bentonit asosida olingan tabiiy mineral pigmentlar. Posterda ko‘rsatilgan qo‘llanish sohalari: devor bo‘yoqlari, fasad qoplamalari, interyer dizayn va dekorativ suvoqlar.
